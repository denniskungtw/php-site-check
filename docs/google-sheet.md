# Google Sheet 版使用說明

[← 回到 README](../README.md)

用 Google Apps Script 在 Google Sheet 裡批次檢查多個網站，結果會自動填入表格並上色。不需要安裝任何軟體。

## 安裝

1. 建立一個新的 [Google Sheet](https://sheets.new)
2. 選單 **擴充功能 → Apps Script**
3. 刪掉編輯器裡原本的內容，貼上 [`php check.js`](../php%20check.js) 的全部內容，按 **儲存**
4. 回到 Google Sheet，**重新整理**頁面
5. 選單列會出現 **PHP 檢查**

第一次執行時，Google 會要求授權。這個腳本只需要兩個權限：

| 權限 | 用途 |
|---|---|
| 查看及管理目前的試算表 | 讀取網址、寫入結果（只限這一份 Sheet） |
| 連線到外部服務 | 對網址送出 GET 請求 |

> 如果出現「Google 尚未驗證這個應用程式」，因為這是你自己建立的腳本，可以按 **進階 → 前往（不安全）** 繼續。

## 使用

### 批次檢查

1. 選單 **PHP 檢查 → 建立 Sites 工作表**
2. 在 `Sites` 工作表 **A 欄第 2 列起**貼上網址，一列一個
3. 選單 **PHP 檢查 → 檢查全部網址**

結果欄位：

| 欄 | 內容 |
|---|---|
| A | 網址 |
| B | 結果（是 PHP / 可能是 PHP / 未發現 PHP 跡象 / 連線失敗） |
| C | PHP 版本（有公開時） |
| D | 版本狀態（已 EOL / 即將 EOL / 支援中） |
| E | 判斷依據 |
| F | HTTP 狀態碼 |
| G | Server 標頭 |
| H | 檢查時間 |

B 欄顏色：

| 顏色 | 意思 |
|---|---|
| 🟥 紅 | 是 PHP，且版本已 EOL 或即將 EOL |
| 🟨 黃 | 是 PHP 或可能是 PHP |
| 🟩 綠 | 未發現 PHP 跡象 |
| ⬜ 灰 | 連線失敗 |

### 儲存格公式

也可以直接在任何儲存格輸入：

```
=ISPHP("https://www.example.com")
```

會回傳像 `是 PHP 7.4.33（已 EOL，請盡快升級）` 的結果摘要。

## 與本機版的差異

| | Google Sheet 版 | 本機版 |
|---|---|---|
| 安裝 | 不用安裝 | 需要 Node.js |
| 批次檢查 | ✅ 表格整理 | ✅ 指令列多個網址 |
| 詳細中文報告 | ❌ 只有摘要 | ✅ 含原始內容、說明、建議 |
| 公司內網 / 限台灣 IP 的網站 | ❌ Google 主機在國外，可能連不到 | ✅ 從你的電腦連線 |

## 注意事項

- Apps Script 單次執行上限約 6 分鐘，每個網站最多會送 3 個請求。網址很多時請分批（建議一次 50 個以內）。
- Google 的 `UrlFetchApp` 每日有呼叫次數上限（一般帳號約 20,000 次）。
- `validateHttpsCertificates` 為開啟狀態，憑證有問題的網站會顯示「連線失敗」。
